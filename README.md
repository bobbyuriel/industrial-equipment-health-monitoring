# Open-source ESP32-Based Dual-Modal Vibration and Acoustic Monitoring Platform for Low-Cost Predictive Maintenance of Industrial Equipment

## Overview

This repository contains the hardware designs, firmware, desktop software, documentation, and validation files for an open-source industrial equipment health monitoring platform developed using an ESP32 microcontroller, MEMS vibration sensing, and acoustic monitoring.

The project accompanies the HardwareX manuscript entitled:

> **Open-source ESP32-Based Dual-Modal Vibration and Acoustic Monitoring Platform for Low-Cost Predictive Maintenance of Industrial Equipment**

The objective of this project is to provide a low-cost, reproducible, and open-source condition monitoring system for predictive maintenance research, engineering education, and industrial applications.
